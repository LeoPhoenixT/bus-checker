# Contributing

Contributions are welcome through GitHub pull requests.

## Development workflow

1. Fork the repository and create a focused branch.
2. Install dependencies with `pnpm install --frozen-lockfile`.
3. Make a narrowly scoped change and add or update tests.
4. Run `pnpm test` and `pnpm build`.
5. Open a pull request describing the change and how it was verified.

Do not commit credentials, personal data, generated build output, or local
environment files. Report security problems privately according to
[SECURITY.md](SECURITY.md).
