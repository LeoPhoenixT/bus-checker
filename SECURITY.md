# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue.

Report them privately through the repository's **Security** tab by opening a
private vulnerability report. Include the affected component, reproduction
steps, potential impact, and any suggested mitigation.

You should receive an acknowledgement within seven days. Please allow a
reasonable remediation period before any public disclosure.

## Supported versions

Security fixes are applied to the latest version on the default branch.
